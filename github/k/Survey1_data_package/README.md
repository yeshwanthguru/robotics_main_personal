# Data for "Quantum Technologies for Autonomous Robotics: A Systematic Survey of Methods, Evidence, and Deployment Constraints"

Authors: Yeshwanth Guru and Dev Kunwar Singh Chauhan, Amrita Vishwa Vidyapeetham, Chennai, India.

| File | Contents |
|---|---|
| `extraction_table.csv` | Data-extraction table for the 72 primary studies |
| `codebook.md` | Definition of every column and code in the table |
| `search_strings.md` | Databases, fields and search strings |
| `quality_appraisal.csv` | Quality appraisal (criteria Q1-Q7, M = met, P = partly met, N = not met) of the 59 graded application studies; Q4 and Q6 to be completed from the full texts before deposit |
