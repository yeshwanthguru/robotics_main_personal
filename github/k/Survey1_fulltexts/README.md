# Survey 1 full texts

Copies of the cited papers found in `quantum_computing/`, renamed by their citation key in
`Survey1_CSUR_LaTeX_Overleaf/refs.bib`. Every file was matched by reading its first page, not its
file name.

- `primary/`: 56 of the 72 primary studies (Table S1). `Salloum2026.pdf` is an image-only
  "Print to PDF" with no text layer; replace it with the publisher PDF.
- `references/`: 72 of the 112 foundational and related works. `Busemeyer2012.pdf` and the
  Nielsen and Chuang book are scanned (no text layer).
- `index.csv`: every cited work, its group, and the source file it was copied from, or MISSING.

Sun2025, Ngo2026, Lathrop2023, OsabaDrone2025, Bang2026, Templier2022, Liu2021, Essalmi2026,
Mannone2023, Mannone2025.
