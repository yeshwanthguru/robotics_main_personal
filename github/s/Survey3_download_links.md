# Survey 3 — papers to download manually

No full text of the 180 reviewed works is in the repository. Save each paper as `<key>.pdf` in `github/s/Survey3_fulltexts/primary/` (primary studies) or `references/` (reviews and software), rerun `python3 tools/make_reference_list.py`, check the write-up and the appraisal codes against the full text, and record any changed code in `Survey3_data_package/quality_appraisal.csv`.

Order: real-robot studies first (they carry the evidence profile), then the core works, then the rest. Each entry has a DOI or arXiv link where one exists, and always a Google Scholar search.
