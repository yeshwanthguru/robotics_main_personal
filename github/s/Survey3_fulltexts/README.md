# Survey 3 full texts (private)

Folder for copies of the cited papers, renamed by their citation key in
`Survey3_TNNLS_LaTeX_Overleaf/refs.bib`.

- `primary/`: primary studies (E2–E5). None present yet.
- `references/`: reviews, software, datasets and method references. Present: `Page2021.pdf` (PRISMA
  2020) and `Kitchenham2007.pdf`, matched by their first-page text.
- `index.csv`: every cited work, its group and evidence level, and its file or MISSING.

All 824 PDFs elsewhere in the repository were searched by arXiv identifier in the file name and by
the title on the first page; none is one of the 180 reviewed works. The download checklist is
`../Survey3_download_links.md`; after adding files, run `python3 tools/make_reference_list.py`.

These are publisher copies for private reference only: keep the repository private and do not
include this folder in the submission package.
