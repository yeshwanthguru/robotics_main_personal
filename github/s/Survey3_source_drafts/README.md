# Survey 3 source drafts

- `Survey3_Paper_Writeups.docx`: one structured write-up for each of the 180 reviewed works (summary,
  extraction fields, edge and signal coding, details to verify), generated from the data package by
  `../tools/make_writeups_doc.py`. Working reference for reading the full texts and for Mendeley.
- `Survey3_Adaptive_Orchestration_Outline.docx`: the section outline (Sections 1–15, Appendices A–F)
  that the manuscript follows.
- `Survey3_Thesis_FINAL.docx`: the thesis-level outline (meta-learning for heterogeneous learning
  orchestration) from which the review question was drawn.

These are working references, not part of the submission. Earlier drafts are in
`quantum_computing/old_drafts/Survey3/` and `quantum_computing/old_drafts/Survey3_IEEE_TNNLS/`.
