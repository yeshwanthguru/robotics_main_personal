**Upload type / Resource type:** Dataset

**Title:**
Data for "Meta-Learning Orchestration of Learning Modalities on Resource-Constrained Robots: A Systematic Review"

**Creators:**
- Guru, Yeshwanth — Department of Mechanical Engineering, Amrita Vishwa Vidyapeetham, Chennai, India — ORCID 0009-0007-6353-4033
- Chauhan, Dev Kunwar Singh — Department of Mechanical Engineering, Amrita Vishwa Vidyapeetham, Chennai, India — ORCID 0000-0002-1466-4567

**Description:**
Supplementary data for a systematic review of how an embodied agent on resource-constrained hardware
can orchestrate several learning modalities (perception, reinforcement learning, imitation, fault
adaptation) with a meta-learned, confidence-driven, compute-budgeted gate. The dataset contains:
(1) the data-extraction table for the 180 included works, with evidence level (E1–E6, review or
software), topic, task, method, setup, key result, limitation, edge footprint and its class,
confidence-signal class, basis of extraction and identifier; (2) the quality appraisal of the 161
primary studies at levels E2–E5 against seven criteria (met / partly met / not met / not assessable);
(3) a summary of each of the 180 works; (4) the codebook and the hand-coding files; (5) the search
strategy; and (6) the code of the illustrative routing simulation. Files are CSV (UTF-8), Markdown and
Python.

**Keywords:** meta-learning; mixture of experts; uncertainty quantification; robot learning; edge
computing; systematic review
